# Ahmed Early Explosion Trader v2.0 FIRST-CANDLE

نسخة مستقلة لجميع عقود Binance USDT-M الدائمة على فريمَي 1H و4H فقط.

## ما تم تثبيته

- 🟡 استعداد مبكر جدًا.
- 🟠 دخول الآن في **أول شمعة كسر فقط**.
- 🔥 بداية الانفجار: تأكيد، وليست دعوة دخول جديدة.
- ⚠️ ضعف الزخم.
- منع شراء وبيع متعارضين لنفس العملة.
- دخول الآن وبداية الانفجار يحتاجان توافق 1H و4H.
- فحص انعكاس لحظي قبل إرسال تيليجرام.
- منع التكرار محفوظ في SQLite حتى بعد إعادة تشغيل Railway.
- تسجيل كل إشارة ملغاة وسبب الإلغاء في `/rejections`.
- ترتيب الفرص حسب جودة التوقيت والتوافق والتدفقات والمخاطرة.
- لا يستخدم RSI أو MACD أو Stoch RSI أو KDJ.

## حدود الدخول

- 1H: أول شمعة، وامتداد أقصى افتراضي `0.70 ATR`.
- 4H: أول شمعة، وامتداد أقصى افتراضي `0.45 ATR`.
- إذا فاتت الشمعة الأولى، لا يرسل دخول الآن.
