# Ahmed Early Explosion Trader v3.0 EARLY-FLOW

نسخة تجريبية فعلية مبنية على مشروعك الحالي.

## الفكرة
- التنبيهات الأساسية: 1H و4H فقط.
- التوقيت الداخلي: 5M لإشارة 1H، و15M لإشارة 4H.
- 🟡 استعداد قبل الكسر الصغير.
- 🔵 دخول الآن عند أول Micro Break وتدفق مبكر.
- 🔥 بداية الانفجار بعد استمرار الحركة.
- لا RSI ولا MACD.
- لا يغير الاتجاه داخل نفس الدورة، ولا يكرر المرحلة.
- يلغي الحالة إذا أصبحت الحركة ممتدة.

## Railway
اربط Volume على `/app/data` وأضف TELEGRAM_BOT_TOKEN وTELEGRAM_CHAT_ID.

## روابط
`/health` `/test-telegram` `/signals` `/stats` `/rejections` `/checkpoints`

## مهم
هذه نسخة تجريبية تحتاج تشغيلًا حقيقيًا ومراجعة مجموعة من التنبيهات، وليست ضمانًا للتنبؤ بكل انفجار.
